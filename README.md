# HC Equipamentos - Website

Site profissional para HC Equipamentos, especialista em manutenção e locação de paleteiras e equipamentos hidráulicos.

## 📋 Sobre

HC Equipamentos é uma empresa autorizada de manutenção preventiva e locação de equipamentos hidráulicos para centros logísticos e indústrias. Este website apresenta os serviços, aplicações e informações de contato.

## 🎯 Funcionalidades

- **Design Responsivo** - Otimizado para mobile, tablet e desktop
- **Seção de Serviços** - Apresentação completa dos serviços oferecidos
- **Aplicações** - Setores e áreas de atuação
- **Contato** - Integração com WhatsApp, Email e Mapa de Localização
- **Footer Informativo** - Links rápidos e informações de contato

## 💻 Como Usar

1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/HC-Equipamentos.git
```

2. Abra o `index.html` em um navegador
```bash
cd HC-Equipamentos
open index.html  # macOS
start index.html # Windows
```

3. Para servir localmente (recomendado):
```bash
# Com Python 3
python -m http.server 8000

# Com Python 2
python -m SimpleHTTPServer 8000

# Com Node.js
npx http-server
```

4. Acesse em `http://localhost:8000`

## 📝 Customização

### Cores
Todas as cores estão definidas em `css/style.css` no `:root`:
```css
:root {
    --primary-blue: #070c10;
    --accent-red: #e63946;
    --whatsapp-green: #25D366;
    --secondary-gray: #5b5b5b;
    --text-dark: #3a708f;
    --text-light: #fff;
}
```

### Conteúdo
Edite o `index.html` para alterar textos, imagens e links.
